# Companion expression references

These eight 180 × 166 PNGs are deterministic QPainter renders on the same
warm matte background. The speaking reference shows a voiced mouth frame.
`tests/test_ui_companion_animation.py` compares rendered states to these files,
checks small and high-DPI render bounds, and covers animation/state lifecycles.

`contact_sheet.png` is a quick visual review sheet for all eight states.
